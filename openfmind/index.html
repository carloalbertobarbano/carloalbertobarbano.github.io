An open fMRI corpus for brain foundation models.

Open-fMIND is a uniformly preprocessed, openly accessible corpus of parcellated fMRI timeseries and functional connectivity matrices, built from public OpenNeuro studies. Every run is processed with fMRIPrep and parcellated under 52 atlases, ready for self-supervised pretraining and connectivity analyses at scale.

Connectivity space

The latent organization of 44,241 runs

Each point is one preprocessed run, placed by UMAP from its full Schaefer-400 connectivity (79,800 Fisher-z edges). Runs do not form one homogeneous cloud: twelve dense clusters hold 36% of runs, rest runs gather in a band, and higher motion concentrates in one region shared by many datasets. No cluster corresponds to a single dataset.

Data

Two versions of the same runs

quasiraw

fMRIPrep output projected onto each atlas, nothing else; shipped with the fMRIPrep confounds, frame-aligned, so you can apply your own denoising.

preproc

The same timeseries after a fixed recipe: confound regression, scrubbing, detrending, band-pass filtering and z-scoring.

Every run is available for every atlas, with one connectivity matrix per timeseries. preproc counts the volumes kept after scrubbing. Each file has a JSON sidecar with the full provenance (download, fMRIPrep, parcellation, denoising, connectivity), and qc.tsv gives per-run motion.

Pipeline

How the data was made

  1. Source data

    Brain BOLD datasets from OpenNeuro, at the snapshot recorded in each dataset description.

  2. fMRIPrep 25.2.3

    One job per subject, without surface reconstruction; output in MNI152NLin2009cAsym at 2 mm.

  3. Parcellation

    Mean signal per region with nilearn (NiftiLabelsMasker, or NiftiMapsMasker for probabilistic atlases). This is quasiraw.

  4. Denoising

    One nilearn.signal.clean call: 24 motion parameters plus white-matter and CSF signals, scrubbing above 0.5 mm FD, detrending, 0.01–0.1 Hz band-pass, z-scoring. Runs with fewer than 50 volumes left are dropped. This is preproc.

  5. Connectivity

    Pearson correlation per run with nilearn's ConnectivityMeasure, stored as float32.

Access

Quick start

Files are packed into ~3 GB tar shards that keep their BIDS paths, split by atlas and by rest / task. A parquet index locates every file, so you can filter, stream whole shards, or fetch a single run with an HTTP range request.

Choose runs with the index, stream with WebDataset

import gzip, json
import pandas as pd, nibabel as nib, webdataset as wds

base = "https://huggingface.co/datasets/cbarbano/open-fmind/resolve/main"
idx = pd.read_parquet(f"{base}/index/preproc_timeseries.parquet",
                      filters=[("atlas", "==", "schaefer400"), ("task_type", "==", "rest")])

urls = [f"{base}/{s}" for s in sorted(idx.shard.unique())]
for sample in wds.WebDataset(urls, shardshuffle=False):
    img = nib.Nifti1Image.from_bytes(gzip.decompress(sample["nii.gz"]))
    ts = img.get_fdata().squeeze().T      # (n_timepoints, n_rois)
    meta = json.loads(sample["json"])     # RepetitionTime, ROILabels, TaskType, ...

Download one atlas and rebuild the BIDS tree

hf download cbarbano/open-fmind --repo-type dataset \
   --include "preproc/timeseries/atlas-schaefer400/*" --local-dir open-fmind
cat open-fmind/preproc/timeseries/atlas-schaefer400/*/shard-*.tar | tar -xf - -i
